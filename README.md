# HorizonTok

Independent native Android app project (Kotlin + Jetpack Compose). This is **not a browser app** and does not embed HTML.

## Direction
- Native Android UI and APK packaging
- Feed, discovery, profile, settings, and video playback modules
- Source adapters for content the app is authorized to access
- Honest freshness/source labels, clear offline vs source failure states
- Russian locale support

## Current status
The initial native Android scaffold is being set up. Real video sources and playback are not connected yet. This project does not spoof SIM-region signals or bypass TikTok regional controls.

## Build
Open this project in Android Studio, sync Gradle, then run the app on an Android device or build an APK.
